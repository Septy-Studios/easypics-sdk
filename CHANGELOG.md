# Changelog

## 0.0.1

First public development release.

- Media uploads from filesystem paths, blobs, and byte buffers.
- Album create, list, get, update, and delete operations.
- Album media listing, attach, and remove operations.
- Typed pagination and API errors.
- Request timeouts and `Retry-After` exposure.
- No automatic retries for write operations.

The `0.0.x` line is intentionally unstable while the public SDK surface is being tested against the production API.
